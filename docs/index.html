Agreement can survive
a change in wording.

A numerical answer is easy to count. An explanation, a program, or a summary may have many valid forms. LSC measures agreement between response representations, so selection can work across both answer formats.

Response A“Earth’s tilted axis changes how much sunlight each hemisphere receives.”
Response B“Seasons result from axial tilt as Earth travels around the Sun.”
Response C“The angle and duration of sunlight vary through the year because Earth is tilted.”

Illustrative paraphrases. Exact string counts split these responses; semantic agreement connects them.

  • SC counts matching answers.

    Sample responses, extract the final answers, and vote by exact match. This is effective when answers have a canonical form; free-form outputs need a way to compare meanings.

  • WUCS compares words.

    Sample responses and rank them by probability-weighted unigram overlap. Selection is inexpensive, but shared vocabulary is an incomplete signal of shared conclusions.

  • USC asks the model to judge.

    Place all candidates in a new prompt and ask the LLM to choose. This supports free-form comparison, while adding a judge pass over a new combined context.

  • LSC compares learned embeddings.

    Append learned summary tokens to each response, reuse its generation cache, and compare the response embeddings obtained from the tokens’ final-layer hidden states. It requires summary-token training and access to model internals.

What LSC
contributes.

The base LLM stays frozen. Training updates only the new summary-token embeddings; a short forward pass through the same model turns each completed response into a representation.

Question→Response→S₁S₂S₃S₄S₅S₆

Six learned tokens per response in the main experiments.

  1. Learned response embeddings

    Supervised contrastive learning brings responses with the same answer label closer and separates those with different labels. Mean pooling and normalization yield one embedding per response.

    One selection mechanism for short answers, explanations, code, and summaries.

  2. Cache-aware selection

    Summary tokens attend to the completed response using its existing KV cache. Only the appended positions need a new forward pass; the response is not encoded again from scratch.

    No separate judge model or combined-candidate judge prompt.

  3. Adaptive neighborhoods

    The optional Dynamic TopK variant examines each candidate’s nearest neighbors. It selects a neighborhood size just before the largest drop in the best average similarity.

    A way to reduce the influence of outliers when the majority set is small.

The scoring rule

Let zi be the normalized mean of the final-layer summary-token states for response i. Pairwise cosine similarity is Sij = zi · zj.

wi = 1N − 1 ∑j ≠ i exp(Sij / τ′)τ′ = 0.5

LSC returns the candidate with the largest score. Exponential weighting gives close neighbors more influence than distant responses. This is a consistency score, not a guarantee that the selected answer is correct.

Where the learned
tokens come from.

Before inference, the special-token embeddings are trained to recognize agreement. The supervision comes from the conclusions of generated responses: responses with the same answer label are positive pairs; different labels form negative pairs.

01 Collect short and long responses

For each source question, generate 10 responses and extract each response’s final answer as a pseudo-label. The training mixture balances short-answer tasks with open-ended explanations derived from MMLU.

Short-answer format · 50%

  • GSM8K 10%
  • MATH 20%
  • TriviaQA 20%

Long-answer format · 50%

  • MMLU with chain-of-thought 25%
  • MMLU with short explanations 25%

The second MMLU variant uses explanations without step-by-step chain-of-thought formatting.

02 Keep the reasoning; store the answer as supervision

MMLU starts as multiple choice. Generation prompts request an explanation without option letters, followed by a standardized final answer. Extract that answer as the label, then remove the final answer sentence from the response. The explanation remains as the training input.

When LSC is useful

Use it when you already sample multiple responses, need one selection procedure across answer formats, and can retain the generation cache. The small selection overhead matters most when generation is already the main cost.

What the results do not imply

Agreement can reinforce a shared mistake. LSC needs trained summary tokens and model-internal access. It does not remove the cost of generating candidates, and it does not win on every model or benchmark.

What changes when the representation changes?

LSC response embeddings vs. sentence embeddings

On Llama 3.1 8B, LSC exceeds fine-tuned SBERT on MATH by 2.2 points (+4.4% relative), TruthfulQA by 0.4 points (+0.9%), and HumanEval by 1.2 points (+2.1%), while scoring 0.3 points lower on TriviaQA (−0.4%). This supports a task-dependent benefit from the learned representation, rather than a universal improvement.

Calibration has its own trade-offs

Lower ECE is better. LSC improves over WUCS on all four reported tasks, but SC has lower ECE on MATH (0.076 vs. 0.140) and TriviaQA (0.044 vs. 0.052). Relative to SC, LSC’s ECE rises by 0.064 (+84.2%) and 0.008 (+18.2%), respectively. Confidence quality should be checked separately from answer selection.

Paper Tables 5–6; Llama 3.1 8B. Accuracy / Truth / Pass@1 values are percentages; ECE is reported on a 0–1 scale.

What to test in your setting
  1. Check whether agreement tracks correctness. Evaluate LSC and the relevant baseline on the same candidate pool. If majority-set selection improves without task quality improving, inspect shared errors before increasing the sampling budget.
  2. Measure the full cost. Time generation and selection separately, then report end-to-end latency and peak memory with and without cache reuse. This tests whether the reported small selection overhead transfers to your serving setup.
  3. Test the adaptive variant. Compare LSC and Dynamic TopK by majority-set size and task. Keep it only where its gains justify the added selection logic; the paper reports mixed results across models.
